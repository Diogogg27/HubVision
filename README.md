# PromptLab - AI Creative Studio

Landing page profissional para servicos de prompts de IA.

## Estrutura

```
LandingPage-Personal/
├── css/
│   └── styles.css          # Estilos principais
├── js/
│   └── main.js             # JavaScript principal
├── images/
│   ├── hero/               # Imagens da secao hero
│   ├── services/           # Imagens de servicos
│   ├── portfolio/          # Imagens do portfolio
│   ├── about/              # Imagens da secao sobre
│   ├── cta/                # Imagens de CTA
│   ├── logo/               # Logotipos
│   └── patterns/           # Padroes e texturas
├── icons/
│   ├── favicon/            # Favicons
│   ├── apple/              # Apple touch icons
│   ├── android/            # Android icons
│   └── social/             # Icones de redes sociais
├── fonts/                  # Fontes customizadas
├── assets/
│   ├── animations/         # Animacoes Lottie/CSS
│   └── videos/             # Videos de fundo
├── palettes/
│   └── colors.json         # Paleta de cores
├── index.html              # Pagina principal
├── manifest.json           # PWA manifest
├── robots.txt              # Robots.txt
└── .gitignore              # Git ignore
```

## Paleta de Cores

| Cor | Hex | Uso |
|-----|-----|-----|
| Cyan | #0087BD | Accent principal |
| Slate | #536878 | Accent secundario |
| Ice | #B2FFFF | Highlights |
| Dark | #0a0e12 | Background |

## Tecnologias

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- JavaScript (ES6+, Canvas API)
- Google Fonts (Outfit)

## Como Usar

1. Abra `index.html` no navegador
2. Personalize as imagens na pasta `images/`
3. Edite os textos no `index.html`
4. Altere as cores no `css/styles.css` ou `palettes/colors.json`
