HubVision Prompt Collector Bot

Guia completo de instalacao e uso

⚙ Pre-requisitos
  • ✓ Python 3.8+ instalado
  • ✓ Conta no Telegram
  • ✓ Acesso ao @BotFather
  • ✓ Grupos de IA no Telegram
💬 Parte 1: Criar o Bot no Telegram
1 Abra o Telegram e acesse @BotFather
No Telegram, pesquise por @BotFather e inicie uma conversa.
2 Crie um novo bot
Envie o comando:
/newbot
O BotFather vai perguntar o nome do bot. Digite algo como:
HubVision Prompt Collector
3 Escolha o username
Escolha um username unico (deve terminar com "bot"). Exemplo:
hubvision_prompt_bot
4 Copie o TOKEN
O BotFather vai enviar uma mensagem com o token. Copie tudo que esta entre colchetes:
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
IMPORTANTE: Guarde este token! Ele e a chave de acesso ao seu bot.
📄 Parte 2: Configurar o Bot
5 Abra o arquivo config.py
Navegue ate a pasta do bot e abra o arquivo config.py:
P:\LandingPage-PromptHub\telegram-bot\config.py
6 Cole o token
Substitua "SEU_TOKEN_AQUI" pelo token que voce copiou:
BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrsTUVwxyz"
💻 Parte 3: Instalar e Executar
7 Abra o terminal (CMD ou PowerShell)
Opcao A: No Explorador de Arquivos, clique na barra de endereco, digite cmd e pressione Enter.

Opcao B: Pressione Win + R, digite cmd e pressione Enter.
8 Navegue ate a pasta do bot
cd P:\LandingPage-PromptHub\telegram-bot
9 Instale as dependencias
pip install -r requirements.txt
Aguarde a instalacao finalizar.
10 Inicie o bot
python bot.py
Se tudo estiver correto, vera:
========================================
HubVision Prompt Collector
========================================
Bot iniciado! Ctrl+C para parar.
Mantenha o terminal aberto! O bot precisa estar rodando para coletar prompts.
👥 Parte 4: Adicionar o Bot aos Grupos
11 Adicione o bot ao grupo
No Telegram, abra o grupo de IA e adicione o bot:

1. Abra o grupo
2. Clique no nome do grupo ( topo )
3. Clique em "Membros"
4. Clique em "Adicionar membres"
5. Pesquise pelo username do seu bot
6. Selecione e adicione
12 Torne o bot ADMINISTRADOR
OBRIGATORIO: O bot precisa ser admin para detectar reacoes!
No grupo:
1. Clique no nome do grupo
2. Clique em "Membros"
3. Toque no nome do bot
4. Selecione "Tornar administrador"
5. Confirme
13 Pegue o ID do grupo
No grupo, envie:
/id
O bot vai responder com o ID do grupo. Copie o numero.
14 Adicione o ID no config.py
Abra o config.py e adicione o ID:
CHAT_IDS = [
  -1001234567890, # Grupo IA Midjourney
  -1009876543210, # Grupo DALL-E
]
DICA: Se deixar CHAT_IDS vazio [], o bot coleta de TODOS os grupos onde esta presente.
15 Reinicie o bot
No terminal, pressione Ctrl+C para parar, depois rode novamente:
python bot.py
✅ Parte 5: Usar o Bot
16 Comece a coletar!
1. Veja uma mensagem com imagem + prompt no grupo
2. Reaja com 👍 na mensagem
3. O bot automaticamente:
    - Baixa a imagem
    - Salva em prompts_library/grupo/
    - Adiciona ao prompts_library.js
4. Pronto! O prompt ja esta na biblioteca do site

🛠 Solucao de Problemas
Bot nao responde comandos:
- Verifique se o token esta correto no config.py
- Reinicie o bot

Bot nao detecta reacoes:
- O bot precisa ser ADMINISTRADOR do grupo
- O grupo precisa ter reacoes habilitadas

Imagens nao sao salvas:
- Verifique se a pasta prompts_library existe
- Verifique espaco em disco

Erro "Module not found":
- Execute: pip install -r requirements.txt
💡 Dicas
✓ Deixe o terminal aberto o tempo todo para nao perder prompts

✓ Use /stats periodicamente para ver quantos prompts coletou

✓ O emoji de reacao pode ser alterado no config.py

✓ O backup e salvo automaticamente em collected_prompts/
